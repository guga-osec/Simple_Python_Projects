# CyberSecurity Python Projects 🔐

## dnsbrute.py 🦾💥
This tool is, as the name says a dns brute force, it searches for subdomains on the website you choose.

## portscan.py ⛶👁️
This tool is similar to Nmap, but of course, worse LOL, in is essence it's scans ports in a website/IP.

## store_info.py 🗃️🗁
I like this one and I think is very interesting the idea because every pentester, or almost anyone that works in cybersecurity,
needs to place his info that he gathered in a notepad or something similar.

With this tool you just run it and type in the information.
In the end It creates a organized file containing all the information you gathered.
